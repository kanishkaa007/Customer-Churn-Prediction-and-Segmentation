# Customer Churn Prediction and Customer Segmentation

## About the Project

This is a Machine Learning project built using Python. The aim of this project is to understand customer behavior and predict whether a customer is likely to leave a telecom company (customer churn). I also used K-Means Clustering to group customers based on their behavior.

While making this project, I learned how to clean data, visualize it, train machine learning models, and compare their performance.
---
## Features
* Data preprocessing and cleaning
* Exploratory Data Analysis (EDA)
* Customer segmentation using K-Means Clustering
* Churn prediction using Logistic Regression
* Churn prediction using Decision Tree
* Data visualization using Matplotlib and Seabornn
---
## Technologies Used
* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
---
## Dataset
This project uses the **Telco Customer Churn Dataset**.
The dataset contains customer information such as:
* Gender
* Senior Citizen
* Tenure
* Monthly Charges
* Total Charges
* Paperless Billing
* Churn Status

The CSV file is included in this repository.
---
## Project Workflow
1. Load the dataset
2. Clean and prepare the data
3. Perform Exploratory Data Analysis
4. Create customer segments using K-Means
5. Train Logistic Regression and Decision Tree models
6. Evaluate the model performance
7. Display business insights
